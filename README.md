# Описание проекта

**EcoQuest** — интерактивное электронное учебное издание по дисциплине **«Методика экологических исследований»**, разработанное для студентов экологических направлений подготовки.

Учебник сочетает теоретический материал, практические задания, вопросы для самостоятельной работы, иллюстрации, глоссарий и итоговый тест.

# Содержание учебника

Учебник включает:

- 15 учебных тем;
- практические задания;
- контрольные вопросы;
- вопросы для самостоятельного изучения;
- итоговый тест;
- профессиональный глоссарий;
- библиографию;
- сведения об авторе;
- информацию о проекте.

# Итоговый тест

Интерактивный тест включает 50 вопросов с автоматической проверкой результатов.

---

# Иллюстрации

Все изображения используются исключительно в образовательных целях.

Иллюстрации посвящены:

- исследованию природных вод;
- биоиндикации;
- биоморфологическому анализу растений;
- исследованию почв;
- дистанционному зондированию Земли;
- ГИС;
- экологическому моделированию.

---

# Назначение

Электронное учебное издание предназначено для:

- лекционных занятий;
- лабораторных занятий;
- практических занятий;
- самостоятельной работы студентов;
- подготовки к итоговому контролю знаний.
